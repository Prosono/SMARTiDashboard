Samtalen

Godkjent fjernhjelp

Fjernhjelp må godkjennes av eieren og utløper etter 30 minutter. Eieren kan trekke tilbake tilgangen når som helst.

Support kan se enhets- og personstatus, styre enheter (også låser) og endre rom, scener og automasjoner. Kamera/video, Home Assistant-konsoll, brukere og systemadministrasjon er ikke tilgjengelig. Utførte endringer beholdes etterpå.

Huben må være oppdatert for å kunne bruke fjernhjelpslenken.
