# SMARTi for Home Assistant

Install from Home Assistant's built-in app store by adding this repository:

https://github.com/Prosono/SMARTiDashboard

[Add repository to Home Assistant](https://my.home-assistant.io/redirect/supervisor_add_addon_repository/?repository_url=https%3A%2F%2Fgithub.com%2FProsono%2FSMARTiDashboard)

SMARTi provides rooms, favorites, lights, switches and thermostat controls using your existing Home Assistant installation. Development preview: real HAOS and physical-device validation remain pending.

See DOCS.md for the two setup options and first-owner login. The complete runtime payload is included in Git; installation does not require a Mac, Node, Samba, SSH or manual file copying.
